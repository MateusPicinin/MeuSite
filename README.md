# 🧑‍💻 Meu Site — Mateus Picinin

> **Transformando conhecimento em projetos e ideias em código.**

Este é o meu **site pessoal e portfólio**, desenvolvido para apresentar um pouco da minha trajetória, meus conhecimentos e alguns dos projetos que venho desenvolvendo durante minha formação em **Ciência da Computação**.

O projeto foi construído do zero utilizando **HTML, CSS e JavaScript**, com foco em criar uma página pessoal com identidade visual própria, navegação simples e apresentação dos meus principais trabalhos.

---

## 🌐 Sobre o projeto

O site funciona como uma apresentação pessoal e um espaço para reunir meus projetos em um só lugar.

A página é dividida em diferentes seções, permitindo apresentar:

* Quem sou e minha trajetória;
* Minha formação em Ciência da Computação;
* Conhecimentos e tecnologias que venho estudando;
* Projetos desenvolvidos durante a graduação;
* Formas de entrar em contato e acessar minhas redes.

A estrutura atual do site conta com uma página principal (`index.html`), um arquivo JavaScript para as interações e uma folha de estilos responsável por toda a identidade visual.

---

## 🎨 Identidade visual

Uma das partes que mais trabalhei no projeto foi a aparência do site.

A interface utiliza uma estética escura com elementos em destaque, transparências, efeitos de hover e uma composição visual baseada em diferentes seções. A fonte utilizada no projeto é a **Ubuntu**, carregada através do Google Fonts.

O objetivo foi criar algo que tivesse uma aparência própria e que, ao mesmo tempo, funcionasse como uma representação do meu estilo enquanto estudante e desenvolvedor.

---

## 🛠️ Tecnologias utilizadas

| Tecnologia       | Utilização                                       |
| ---------------- | ------------------------------------------------ |
| **HTML5**        | Estrutura e organização das páginas              |
| **CSS3**         | Estilização, layout, efeitos e identidade visual |
| **JavaScript**   | Interações e direcionamento dos botões           |
| **Google Fonts** | Utilização da fonte Ubuntu                       |

O projeto não depende de frameworks para sua estrutura principal, sendo desenvolvido diretamente com as tecnologias fundamentais da Web.

## 🚀 Projetos

O portfólio apresenta alguns dos projetos que desenvolvi durante minha formação:

### ⚓ Batalha Naval

Jogo desenvolvido em **Python**, com tabuleiro 10x10, posicionamento de navios, ataques contra o computador, validação de entradas e lógica de programação.

### 🗄️ Banco de Dados

Projeto de banco de dados desenvolvido para um **Pet Shop**, trabalhando com tabelas, relacionamentos, chaves primárias, chaves estrangeiras e SQL.

### 🤖 Machine Learning

Projeto desenvolvido em **Python** utilizando **YOLO** para detecção de objetos em imagens e vídeos.

### ✂️ Jokenpô

Jogo desenvolvido em **Python** com os modos:

* Humano x Humano;
* Humano x Robô;
* Robô x Robô.

Os projetos são apresentados em cards no site, com imagens, descrições e botões que direcionam diretamente para seus respectivos repositórios.
